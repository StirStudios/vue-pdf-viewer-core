# Post-Publish Checklist

1. Verify npm page:
   - https://www.npmjs.com/package/vue-pdf-viewer-core
2. Verify GitHub repo:
   - https://github.com/StirStudios/vue-pdf-viewer-core
3. Enable GitHub Pages:
   - Settings → Pages → Deploy from branch `gh-pages`
   - `/playground/` and `/nuxt/` paths
4. Check Actions:
   - CI
   - Deploy Playground
   - Deploy Nuxt Playground
5. Share release notes and link.
